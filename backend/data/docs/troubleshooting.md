# Troubleshooting

## No mobile data in Sweden

1. Check for a known outage in your area.
2. Make sure mobile data is switched on and flight mode is off.
3. Check whether you have used your data allowance; if so, your speed is reduced.
4. Restart the phone.
5. Check that the access point name (APN) is set to "martins".
If none of these help, contact customer service.

## Mobile data not working abroad

1. Make sure data roaming is switched on in the phone's settings.
2. Check that the country is in one of our roaming zones; countries outside all zones are not covered.
3. Check whether your monthly roaming spending limit has been reached.
4. Select a partner network manually in the network settings.
5. Restart the phone.

## Slow data speeds

Speeds can be slow because of network congestion, weak coverage indoors, or because your data
allowance is used up. Check for outages in your area, and try moving closer to a window.

## No signal or "SOS only"

Check for an outage in your area. Remove and reinsert the SIM card, or for an eSIM, check that
the eSIM line is enabled. If the problem remains after a restart, the SIM card may be faulty
and can be replaced free of charge by customer service.

## eSIM setup

An eSIM is activated by scanning the QR code sent by email. Each QR code can only be used once.
If you change phone, request a new eSIM QR code from customer service.
